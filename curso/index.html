Tutor socrático (opcional)

Cuando se conecte el proxy, el tutor podrá explicar conceptos y darte pistas graduales sin resolverte los retos.

La web estática no puede esconder una clave. No pegues tu API key aquí: este sitio aún no tiene un backend seguro. Un `venv` solo aísla paquetes en tu computadora; no protege secretos en GitHub Pages. GitHub Actions Secrets tampoco llegan al navegador y nunca deben incrustarse en los archivos publicados.

Para activarlo de forma segura hace falta un pequeño proxy del lado servidor que guarde `NVIDIA_API_KEY` como secreto (por ejemplo, en un Cloudflare Worker). La web enviaría solo tu pregunta y el reto actual a ese proxy, nunca la clave. El rol e instrucciones del tutor ya están documentados para ese backend.
